# Manuscript submitted to *Array* (Elsevier)

**Preprint.** This is the version submitted to the journal *Array* (Elsevier) in
November 2026. It has not been peer reviewed. If it is published, a link to the
published article will be added here.

- `main.pdf`: the manuscript (13 pages)
- `main.tex`, `refs.bib`, `figs/Figure_1..6.pdf`: the LaTeX source. It uses
  Elsevier's CAS template (`cas-sc`, in TeX Live's `els-cas-templates`) and
  builds with `latexmk -pdf main.tex`.

The results are identical to the earlier IEEE-format draft in [`../`](../). This
version adds the authors, the declarations the journal requires, and a shorter
abstract (250-word limit), and fixes some small wording points.

Authors: Abu Hasnat Emad, Md Atiqur Rahman Rohid, Md Sakib Uddin Niloy,
Kazi Jaberul Islam Nafi, MD. Siamul Islam Apurbo, Md Juwel Mia and
Muhammad Nomani Kabir (Department of Computer Science and Engineering,
United International University, Dhaka, Bangladesh).
